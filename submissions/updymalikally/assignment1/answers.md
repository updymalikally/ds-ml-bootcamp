Define Machine Learning using a real-life example


Machine Learning is a part of Artificial Intelligence that allows computers to learn from data and improve their performance without being explicitly programmed.
Example:
Mobile phones use Machine Learning for face recognition. The phone learns from images of the user’s face and becomes better at unlocking the device even if lighting or facial expressions change.

Question 2 : Compare Supervised Learning and Unsupervised Learning, giving an example of each?.

Supervised Learning:
In supervised learning, the dataset is labeled, meaning the correct output is already known. The model learns by comparing its predicted output with the actual output.
Example:
Student result prediction.
The model is trained using data such as marks and the final result (pass/fail). It then predicts whether a new student will pass or fail.

Unsupervised Learning:

Unsupervised learning uses unlabeled data, where no correct output is provided. The model finds patterns or groups in the data.
Example:

Grouping students based on study habits.
Students are grouped based on attendance, study hours, and performance without knowing the groups beforehand.

Question 3:What causes Overfitting? How can it be prevented?.

Causes of Overfitting:
Too much focus on training data
Very complex model
Small training dataset
Prevention of Overfitting:
Use more training data
Use a simpler model
Stop training early
Use proper data splitting

Question 4 : Explain how training data and test data are split, and why this process is necessary.?

Training data:

Training data is the portion of data used to train the Machine Learning model.
Test data:
Test data is the portion of data used to test the accuracy and performance of the model.
Why splitting is necessary:
Data splitting helps us check whether the model works well on new and unseen data and helps avoid overfitting.

5. Case Study: Application of Machine Learning in Healthcare

One example of using machine learning in healthcare is in predicting hospital admissions. In this study, researchers used patient data such as age, medical history, and medication records to train machine learning models. The goal was to predict which patients were likely to be hospitalized in the future.

The study found that machine learning models could predict hospitalizations with good accuracy. It also showed that patients who followed their treatment and preventive care had fewer hospital visits. This helps doctors give better care and reduce healthcare costs.

Summary of Findings:

Machine learning can analyze patient data.

It helps predict future hospital visits.

Doctors can use this to improve treatment.

It reduces unnecessary hospital expenses.
